# 待拼图纸与实际豆子分层修正

用户明确纠正：图片转换后应在画布显示每格颜色与色号供用户亲自拼豆，导入不能提前填好珠子；现有本地图纸导出正确，继续保留。此纠正足以确定行为，直接落实，不重复请求审批。

采用现有画布内的只读目标图纸 + 可编辑豆子双层。新导入画布的 board.cells 全为空；reference 升级 schema 2，加入 width、height 和 cells（MARD code/null），items 保持目标用量。目标色块和色号在空格上呈现，实际放豆仍走既有逐格规则，擦除只擦实际豆子，露出原图纸。允许自由选色，不强制色号校验、不自动补豆。

共用同一 reference 快照同步给房间，保存在现有画布库。目标图纸保留原尺寸，扩展向右/下留白，源行列到扩大后的行列映射不能漂移；清盘保留底图、备份保留豆子进度；新建普通画布无底图。schema 1 及已有作品按原样加载，不自动清空或猜测旧图纸。

画布空格显示平面目标颜色和完整色号；可读字号下显示全部色号，缩小时保留颜色、坐标栏显示所选目标色号，放大查看。已放豆呈现原有有孔珠子。颜色盒目标量来自图纸、当前量只统计实际珠子。待拼图纸存在时“导出色号图纸”导出完整目标图纸，4K 仍导出实际作品。

不采用将目标豆子改成半透明 actual cells（仍然占格）；不采用客户端临时底图（刷新和伙伴不可恢复）。不修改用户实际 data/；测试使用临时目录。现有自动填好的旧画布不自动改成待拼图纸；用户可重新上传原图导入，旧画布保留。
