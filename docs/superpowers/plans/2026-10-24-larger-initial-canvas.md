# 初始画布空间调整与 GitHub 发布

用户要求初始画布占比更大并上传现有公开 GitHub 仓库。属于现有界面的局部调整，直接执行；沿用视觉风格，不改变实际作品与图纸规则。

## 方案

首次进入默认收起侧色盘和颜色盒；用户明确保存的展开偏好继续保留。侧色盘主要释放宽度，颜色盒释放高度；同时收紧页面外框间距，并将适应画板的缩放上限从 1.4 调到与手动缩放相同的 4，使小画布能够利用新增空间。所有常用工具保留 44px 点击区，工具不覆盖格子，完整画布仍在适应范围内。

只扩大缩放会裁掉画布，单独收侧栏对高度受限的方形图纸帮助不足，因此结合默认收起和紧凑外框。只压缩视觉留白，不降低渲染清晰度。
